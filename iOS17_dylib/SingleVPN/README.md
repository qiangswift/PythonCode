# Single VPN

Combine VPN state and wireless state into one icon.

Version 2.3.0 records upload and download totals for every link-layer network
interface. The Settings landing-page overlay remains limited to cellular and
Wi-Fi summaries; the tweak preference page lists each interface separately.
Sampling remains hourly, with one immediate extra sample when the preference
page opens. VPN, peer-to-peer and bridge interfaces remain separate from the
landing-page totals to avoid tunnel and physical-interface double counting.
